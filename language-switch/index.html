For Content Creators / 对于内容创作者

To create multilingual content:

  1. Create separate posts for each language
  2. Add lang: en or lang: zh-CN to the front matter
  3. Use appropriate categories and tags for each language
  4. Link between language versions if needed

创建多语言内容：

  1. 为每种语言创建单独的文章
  2. 在front matter中添加 lang: en 或 lang: zh-CN
  3. 为每种语言使用适当的分类和标签
  4. 如需要，在语言版本之间建立链接

Language Files / 语言文件

The site uses language files located in the languages/ directory:

  • zh-CN.yml - Simplified Chinese translations
  • en.yml - English translations

网站使用位于 languages/ 目录中的语言文件：

  • zh-CN.yml - 简体中文翻译
  • en.yml - 英文翻译
