Branch Naming Suggestions

  • main/master - Main branch
  • develop - Development branch
  • feature/xxx - Feature branch
  • hotfix/xxx - Hotfix branch
  • release/xxx - Release branch

Note: Force push (git push -f) and hard reset (git reset --hard) will lose data, use with caution!

Document Features

  1. Complete classification system - Commands are divided into 9 major categories
